# **App Name**: SortlyAI

## Core Features:

- AI File Pulling: Use AI to automate the pulling of files from an Android device.
- AI File Sorting: Use an AI tool to sort files based on their content and metadata.
- AI File Organization: Use an AI tool to organize files into predefined categories.
- File Display: Display the files and their categories in a clear, organized manner.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and modern feel.
- Secondary color: White (#FFFFFF) for a clean and uncluttered background.
- Accent color: Pastel green (#77DD77) for highlights and interactive elements.
- Clean and structured layout to ensure a professional look and feel.
- Use a professional font for readability and a polished aesthetic.
- Use a consistent set of professional icons to represent file types and categories.
